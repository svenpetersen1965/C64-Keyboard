The position information was obtained by measuring an original C64 keyboard plastic shield with calipers (a normal and an extral long one).

The data was further processed to even out failure and to finally calculate the switch positions on the PCB.

The "gap" left of the function keys occures on classic C64. Moving the function keys 0.7mm to the left would center them. 

I decided against doing so, because the original position would fit all cases, while I don't know, if a corrected position will do. 

Note: moving the function keys will require modifying the 3D ptintable plates, as well.
